# بوت موسوعة قوانين MTA:SA

بوت Discord باللغة العربية يرد برسائل Embed عند كتابة اختصار القانون أو اسمه في روم واحد فقط.

## الإعدادات
- Server ID: `1183860758069641397`
- Channel ID: `1575596978602115204`
- عدد القوانين المحملة: **111**
- Node.js 18.17+ و discord.js v14

## أمان التوكن
إذا سبق وأرسلت التوكن في محادثة أو نشرته في مكان عام، اعتبره مكشوفاً:
1. افتح Discord Developer Portal.
2. اختر التطبيق ثم Bot.
3. اضغط Reset Token وأنشئ توكناً جديداً.
4. ضع التوكن الجديد محلياً في `.env` فقط. لا ترسله لأي شخص ولا ترفعه إلى GitHub.

## إنشاء البوت
من https://discord.com/developers/applications أنشئ تطبيقاً ثم Bot.
فعّل **Message Content Intent** من صفحة Bot.
ادعُ البوت إلى السيرفر مع الصلاحيات:
- View Channels
- Send Messages
- Read Message History
- Embed Links

لا يحتاج Administrator.

## التشغيل
1. فك الضغط وارفع الملفات إلى استضافتك.
2. انسخ `.env.example` وسمّ النسخة `.env`.
3. ضع التوكن الجديد في `DISCORD_TOKEN`.
4. شغّل:

```bash
npm install
npm start
```

## تعديل القوانين
كل القوانين موجودة في `laws.json`. لكل قانون:
- `code`: الاختصار.
- `name`: اسم القانون.
- `aliases`: الاختصارات والكلمات التي يتعرف عليها.
- `description`: تعريف مختصر.
- `details`: الشرح.
- `examples`: أمثلة.
- `punishment`: العقوبة.

العقوبات مكتوبة بصيغة عامة لأن كل سيرفر يحدد التحذير والسجن والباند ومددها بنفسه. راجع القوانين قبل اعتمادها، فبعض البنود تختلف بين سيرفرات MTA:SA.

## حدود الرد
الكود يتحقق من Server ID وChannel ID قبل قراءة القانون أو الرد، لذلك لا يجيب في أي روم آخر.
